# Пробник резьбы: чек-лист визита

Печатаем 4 тестовых кольца, чтобы узнать, с каким зазором резьба Дна будет навинчиваться на Нижнюю Тарелку на этом принтере и этим пластиком. Дно — съёмная крышка снизу Щита, Нижняя Тарелка — деталь, на которую она накручивается.

Принтер: Anycubic Kobra 2 Neo, пластик PETG.

## 1. Принести

- [ ] флешка с 4 файлами из `dist/coupon/` (после `build.cmd`):
  - `ring-dish.stl` — кольцо Тарелки: резьба внутри, открыто с обеих сторон
  - `ring-floor-0.3.stl` — кольцо Дна, зазор 0.3 мм
  - `ring-floor-0.4.stl` — кольцо Дна, зазор 0.4 мм
  - `ring-floor-0.5.stl` — кольцо Дна, зазор 0.5 мм

  Кольца Дна — с резьбой снаружи и с донышком.

## 2. Поставить в слайсере

Берём профиль PETG друга и меняем только это:

- [ ] высота слоя 0.2
- [ ] 3 периметра (стенки)
- [ ] поддержки выключены
- [ ] brim выключен, skirt тоже, если на столе тесно
- [ ] кольца лежат плашмя, как пришли в STL: не поворачивать. Кольцо Тарелки лежит на столе скошенным краем, кольца Дна — донышком
- [ ] все 4 на одном столе. Вместе они ≈202 × 202 мм при столе 220 × 220 — тесно. Слайсер может сам расставить каждое кольцо по центру: тогда разложить сеткой 2×2 (кнопка авто-расстановки), чтобы не пересекались

Остальное — как в профиле друга, не трогать: подбираем зазор именно под его обычные настройки.

## 3. Записать

С профиля друга, до печати (фото экрана тоже подойдёт):

- [ ] слайсер и его версия, название профиля
- [ ] ширина линии
- [ ] поток (flow)
- [ ] XY-компенсация (размера отверстий и внешних контуров)
- [ ] компенсация «слоновьей ноги» (первого слоя)
- [ ] температура сопла и стола
- [ ] обдув (вентилятор детали)

## 4. Какое кольцо какое

Насечки — пазы на донышке кольца Дна, с внутренней стороны. Заглянуть в кольцо и посчитать:

| насечек | зазор |
|---|---|
| 1 | 0.3 |
| 2 | 0.4 |
| 3 | 0.5 |

## 5. Проверить

Каждое кольцо Дна по очереди накрутить в кольцо Тарелки.

Подошло, если:

- [ ] навинчивается рукой на все 3 витка, без заеданий
- [ ] вкрученное до конца при покачивании не стучит

| зазор | подошло? |
|---|---|
| 0.3 | |
| 0.4 | |
| 0.5 | |

## 6. Выбрать

Берём самое плотное из подошедших и добавляем один шаг (0.1), но не больше самого свободного из подошедших. Запас — на зиму: Дно откручивают на морозе, в грязи и инее.

| подошли | берём |
|---|---|
| 0.3, 0.4, 0.5 | 0.4 |
| 0.3, 0.4 | 0.4 |
| 0.4, 0.5 | 0.5 |
| только 0.4 | 0.4 |
| только 0.5 | 0.5 |
| только 0.3 | 0.3 |

Выбрано: ____

## 7. Если не вышло

- **ни одно не подошло** (все туго или все болтаются) — печатаем второй набор: те же кольца, зазоры сдвинуты в нужную сторону
- **сами зубья резьбы печатаются плохо** при любом зазоре: крошатся, расслаиваются, нижняя сторона зуба оплыла — резьбу бросаем, Дно будет крепиться байонетом (поворотом на четверть оборота, как крышка объектива)
