# Щит для POK005L — фазы

> Утверждено картой `.scratch/shield/map.md` (тикет «Утвердить план фаз»).

ТЗ: [PLAN.md](../PLAN.md). Термины: [GLOSSARY.md](../../GLOSSARY.md).

Порядок — сверху вниз от Скелета: сначала точный Датчик, потом общая болванка всего Щита, потом детализация деталей, каждая берёт размеры из Скелета. Spec фазы пишется в её grilling-сессии: `.scratch/<фаза>/spec.md`.

Все Стыки — именованные параметры Скелета в одном файле. Фазы их только читают; поменять Стык — править Скелет и пересобрать. Поэтому фазы 4, 5, 6 друг от друга не зависят и идут в любом порядке.

## 0. Окружение

- **цель**: воспроизводимый запуск сборки из VS Code
- **вход**: —
- **выход**: структура репо (`models/`, `src/`, `output/`), `freecadcmd src/build.py` создаёт пустой FCStd; заготовка проверок геометрии (битое тело или пересечение деталей роняет сборку с понятной ошибкой, каждая фаза добавляет свои); сборка сохраняет PNG-виды сцены (спереди, сбоку, сечение по оси), чтобы агент видел результат. Если PNG из FreeCAD не выйдет — запасной путь: OpenSCAD рендерит экспортированные STL
- **готово, когда**: один запуск из терминала VS Code даёт файл, который открывается в FreeCAD, и PNG-виды; намеренно битое тело роняет сборку

## 1. Контрольная сцена Датчика

- **цель**: узнать реальную геометрию Датчика
- **вход**: 0
- **выход**: импорт STL половин Корпуса и Крючка, половины свинчены, понятно как цепляется Крючок; реальный габарит Датчика и упрощённое тело-заглушка
- **готово, когда**: габарит собранного Датчика измерен в сцене, заглушка его повторяет

## 2. Скелет Щита

- **цель**: общая параметрическая болванка всего Щита
- **вход**: 1
- **выход**: параметры и оси, грубые тела всех деталей (Тарелки, Крышка, Стойки, Дно, Держатель, болванка Кронштейна), Датчик-заглушка внутри. Стыки — параметры в одном файле:
  - Крышка↔Кронштейн: точка подвеса (центр верха Крышки, ось болта = ось Щита), болт M6, высота проставки
  - Тарелки/Крышка↔Стойки: число Стоек, радиус их расположения, отверстие под Шпильку M4
  - Дно↔нижняя Тарелка: диаметр и шаг резьбы, зазор
  - Щит↔Откос: расстояние до кирпича
  - Датчик↔Держатель: форма Крючка (из фазы 1)
- **готово, когда**: все Стыки — параметры в одном файле; смена диаметра Щита и числа Тарелок пересобирает болванку без ошибок; Датчик-заглушка не касается тел; проверки фазы 0 проходят

## 3. Пробник резьбы

- **цель**: проверить резьбу Дна печатью до того, как начато Дно
- **вход**: 2 (диаметр, шаг, зазор резьбы)
- **выход**: STL пары тестовых колец, друг печатает; найденный зазор записан в Скелет
- **готово, когда**: напечатанные кольца свинчиваются рукой без люфта. Не выходит — переход на байонет, Стык Дно↔нижняя Тарелка меняется в Скелете

## 4. Тарелки и стопка

- **цель**: Тарелки, которые закрывают Носик от солнца
- **вход**: 2
- **выход**: профиль Тарелки (от SanglierLab, под нашу полость), Тарелки ×N, Крышка с гнездом под закладную гайку по Стыку Скелета, Стойки под Шпильки M4
- **готово, когда**: в сечении низкое солнце (0–15°) не видит Носик

## 5. Дно и Держатель

- **цель**: съёмное Дно с Датчиком
- **вход**: 2, 3
- **выход**: Дно с резьбой по проверенному зазору, Держатель с Крючком, Датчик висит Носиком вниз
- **готово, когда**: в сцене Датчик-заглушка висит на Крючке Носиком вниз; Дно с Держателем и Датчиком выходит вниз без столкновений; резьба проходит проверки геометрии

## 6. Кронштейн

- **цель**: Щит висит на покупном Кронштейне за Крышку
- **вход**: 2 (точка подвеса, болт, проставка, расстояние до Откоса), купленный и обмеренный Кронштейн (форма — по схеме пользователя; покупка сразу после Скелета, т.к. вылет зависит от диаметра Щита)
- **выход**: что купить, проставка (с защитой от проворота по обмеру), модель Кронштейна по обмеру вместо болванки в Скелете
- **готово, когда**: модель купленного Кронштейна стоит в сцене вместо болванки; Щит висит на оси болта; расстояние до Откоса = параметру Скелета; пересечений нет

## 7. Печать

- **цель**: детали готовы к печати
- **вход**: 4, 5, 6
- **выход**: ориентация каждой детали на столе, проверка нависаний, экспорт STL/FCStd; пробник куска Тарелки — при желании
- **готово, когда**: у каждой детали есть STL и указана ориентация на столе

## 8. Инструкция

- **цель**: README для печати, сборки и смены батарейки
- **вход**: 7
- **выход**: `README.md`
- **готово, когда**: в README есть разделы «печать», «сборка», «монтаж», «смена батарейки»
