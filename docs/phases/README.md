# Щит для POK005L — фазы

> Черновик. Утверждается картой `.scratch/shield/map.md` (тикет «Утвердить план фаз»).

ТЗ: [PLAN.md](../PLAN.md). Термины: [GLOSSARY.md](../../GLOSSARY.md).

Порядок — сверху вниз от Скелета: сначала точный Датчик, потом общая болванка всего Щита, потом детализация деталей, каждая берёт размеры из Скелета. Spec фазы пишется в её grilling-сессии: `.scratch/<фаза>/spec.md`.

## 0. Окружение

- **цель**: воспроизводимый запуск сборки из VS Code
- **вход**: —
- **выход**: структура репо (`models/`, `src/`, `output/`), `freecadcmd src/build.py` создаёт пустой FCStd
- **готово, когда**: один запуск из терминала VS Code даёт файл, который открывается в FreeCAD

## 1. Контрольная сцена Датчика

- **цель**: узнать реальную геометрию Датчика
- **вход**: 0
- **выход**: импорт STL половин Корпуса и Крючка, половины свинчены, понятно как цепляется Крючок; реальный габарит Датчика и упрощённое тело-заглушка
- **готово, когда**: габарит собранного Датчика измерен в сцене, заглушка его повторяет

## 2. Скелет Щита

- **цель**: общая параметрическая болванка всего Щита
- **вход**: 1
- **выход**: параметры и оси, грубые тела всех деталей (Тарелки, Крышка, Стойки, Дно, Держатель, болванка Кронштейна), Датчик-заглушка внутри
- **готово, когда**: ?

## 3. Тарелки и стопка

- **цель**: Тарелки, которые закрывают Носик от солнца
- **вход**: 2
- **выход**: профиль Тарелки (от SanglierLab, под нашу полость), Тарелки ×N, Крышка, Стойки под Шпильки M4
- **готово, когда**: в сечении низкое солнце (0–15°) не видит Носик

## 4. Дно и Держатель

- **цель**: съёмное Дно с Датчиком
- **вход**: 2
- **выход**: стык Дна с нижней Тарелкой, Держатель с Крючком, Датчик висит Носиком вниз
- **готово, когда**: ?

## 5. Кронштейн

- **цель**: крепление Щита к Откосу
- **вход**: 2
- **выход**: узел на Крышке + Кронштейн (печатный или покупной — открыто)
- **готово, когда**: ?

## 6. Печать

- **цель**: детали готовы к печати
- **вход**: 3, 4, 5
- **выход**: разбивка на детали, ориентация на столе, допуски, экспорт STL/FCStd, тестовый образец стыка Дна
- **готово, когда**: ?
